# Шрифт дневника (§136)

`Caveat-Regular.ttf` — это `Caveat[wght].ttf` из репозитория Google Fonts,
переименованный под путь, по которому его грузит код
(`Resources.Load<Font>("HexLive/UI/Fonts/Caveat-Regular")`).

Это **вариативный** шрифт: Unity импортирует его дефолтным начертанием.
Кириллица полная — проверено, все 33 буквы обоих регистров плюс Ё на месте
(220 кириллических глифов из 753).

Лицензия — SIL Open Font License 1.1, файл `OFL.txt` рядом. Коммерческое
использование и распространение в составе игры разрешены; условие одно —
сохранять текст лицензии.

⚠️ Если файла нет, `CharacterPanel.Journal.cs` молча остаётся на дефолтном
шрифте UI Toolkit: отсутствие шрифта не должно превращать страницу в пустое
окно.
