# Agent Studio: единый доступ HexLive

1. При первом запуске введите выданный вам ключ `hexlive_…`. Это тот же ключ,
   что используется в игре. Отдельный client ID и предварительный запуск игры не нужны.
2. Проверенный ключ сохраняется в Windows Credential Manager / macOS Keychain.
   Следующие запуски используют его автоматически. В профили и экспорт памяти ключ не попадает.
3. Выберите Сингапур, подключитесь и выберите доступного персонажа.
   Нью-Йорк в этой фазе тестирования отключён. Произвольные адреса скрыты.
4. Подключение получает авторизованный каталог MCP, мир и персонажей.
   Оно не запускает модель, голос или управление персонажем. Play запускает агента.
5. Раздел «Серверы» → «Сменить ключ доступа» позволяет сменить учётную запись.
   Работающие агенты сначала останавливаются. Неверный ключ не заменяет сохранённый.

Ключу требуется `game.play`; `server.admin` предоставляет административный доступ
по серверным правилам. Отдельной роли «агент Studio» нет. Игра и Studio используют
одну учётную запись. Права назначаются и изменяются в единой админке ключей.
Сервер проверяет ключ и актуальные права для каталога, чтения и команд.
Отозванный ключ не позволяет продолжать работу через уже открытую сессию.

Ключи OpenAI, Grok, Claude, DeepSeek и ElevenLabs — отдельные учётные данные
внешних сервисов. Они настраиваются в «Интеграциях» и не заменяют ключ HexLive.

При обновлении старые локальные профили и память сохраняются. Подключение
Сингапура переводится на единый ключ; старые пользовательские адреса не выводятся
в списке официальных серверов. Общий ключ никогда не отправляется на такой адрес.
