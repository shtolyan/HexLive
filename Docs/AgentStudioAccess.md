# Agent Studio: подключение к серверу

## Обычное подключение — адрес и токен

1. Шестерёнка → «Серверы» → «Добавить сервер».
2. Введите адрес (например, `https://vmi3529459.contaboserver.net/mcp`) и
   **тот же серверный токен, который используете в HexLive**.
3. Нажмите «Подключить и сохранить». Личность собранного игрового клиента
   Studio читает автоматически. Коды, запросы и подтверждение в админке не нужны.
4. У агента нажмите значок соединения, выберите сервер → Connect.
5. Выберите одного из возвращённых сервером персонажей. Другой профиль агента
   может использовать это же подключение и другого вашего персонажа.
6. Play запускает модель. Connect сам по себе LLM/TTS не вызывает.

Если игра на этом компьютере ещё не подключалась, сначала запустите HexLive
и зайдите на сервер. Studio не создаёт нового player ID и не использует ID
Unity Editor. Поддержаны macOS PlayerPrefs и Windows PlayerPrefs в реестре.
Реальный Windows-прогон выполняется на Windows отдельно.

## Список серверов

Сохранённые подключения видны списком. «Добавить сервер» создаёт подключение,
«Изменить» открывает адрес и токен выбранного. При редактировании адреса без
изменения токена можно оставить поле токена пустым. При смене адреса нужно
ввести токен явно — старый секрет не отправляется на другой сервер автоматически.
Неудачная проверка не заменяет сохранённое подключение.
Токены хранятся в Keychain / Credential Manager, не в профилях.

## Разные виды токенов

- Игровой серверный токен: доступ к NPC вашего сохранённого player ID.
- Старый глобальный MCP-токен `hexmcp_…`: широкий доступ к NPC, как у прежнего
  AgentHost; поддержан в том же поле. Не выдавайте его обычным игрокам.
- Grok, OpenAI, DeepSeek, ElevenLabs: ключи моделей и речи, сюда не подходят.
- Разрешение голосового администратора («вылечить», изменить мир) — отдельная
  функция игры, не условие подключения Agent Studio.

Игровой токен сейчас общий; player ID, как и в игровом клиенте, передаётся
отдельно. Это не персональная криптографическая учётная запись. Не выдавайте
общий токен недоверенным пользователям. MCP фильтрует список и команды по
актуальным назначениям сервера и привязывает сессию к ID и миру.
