# Визуальный эталон Agent Studio

`approved-mockup.png` — исходный одобренный пользователем макет, не скриншот
работающей программы. Данные и статусы на нём демонстрационные.

Обязательные ориентиры реализации:

Уточнение 2026-09-08: главный экран теперь компактный пульт 560×300, а не
большой кабинет из исходной картинки. Настройки/сознание/подключение открываются
отдельно. Этот новый запрос пользователя имеет приоритет над компоновкой макета.

- Графитовая основа, чуть различающиеся фон/боковая панель/поля; бирюзовый акцент.
- Слева список агентов и «+», справа статус и три крупные кнопки-иконки
  подключения/Play/Stop с подсказками; настройки и сознание открываются отдельно.
- Статус отделён от настроек и активности. Нет фиктивного «подключён» или баланса.
- Интеграции: провайдеры слева, выбранная интеграция справа.
- Память: навигация по реальным файлам слева, документ справа, сохранение с версией.
- Диалог выхода: компактное пояснение последствий, кнопки в нижнем правом углу;
  отмена получает начальный фокус, Escape отменяет, выход акцентирован красным.
- Родные системные заголовки macOS/Windows; не рисовать чужие кнопки окна.
- Светлая тема использует ту же компоновку, не инвертированный макет-картинку.

Проверка после сборки: главное окно, выход/отмена, обе темы, интеграции,
настройки профиля, серверы, память/душа, узкое окно и масштабирование ОС.
Исходный макет не является доказательством прохождения этих проверок.
