## Граница выполнения

Снята точка отката. На этом этапе новый мир **не создан**, активный release
не переключён, сервис не перезапускался. Текущее состояние реализации desktop
описано в `Server/HexLive.AgentStudio/IMPLEMENTATION.md`, не выдавать preview за
готовую интеграцию. Перед rollout пройти канонические проверки CLAUDE.md и
зафиксировать разворачиваемые изменения отдельно, без чужих dirty-файлов.

Следующий тестовый мир предполагает прежний формат HugeIsland с новой Машей
и Никой. Создавать его через штатную библиотеку/авторизованный admin flow,
не перезаписывать папку старого мира. Локальную душу и память Маши не обнулять:
новое тело/мир — новая история в прежней памяти.

Важно: старый release не сериализует операторскую паузу. Простое восстановление
сейва и `systemctl start` начинает считать тики. RESTORE.md требует оставить
восстановленный сервис остановленным до подготовленного контролируемого запуска;
нельзя заявлять, что пауза автоматически переживает restart.
