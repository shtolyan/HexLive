# Навыки игрового агента

Studio читает встроенные процедуры из `AgentPrompts/skills.json`, а дополнения
конкретного профиля — из `<MASHA_HOME>/skills/catalog.json`. Это справочные
данные для `skills.list/read`, а не исполняемые скрипты. Навык не разрешает
новые MCP-команды и не заменяет актуальную спецификацию или рецепты мира.

Пример нового кандидата:

```json
{
  "prepare-camp": {
    "status": "candidate",
    "version": 1,
    "title": "Подготовить запасы лагеря",
    "specSections": ["128"],
    "procedure": [
      "Уточнить нужные запасы и прочесть актуальные правила хранения.",
      "Проверить вместимость и известные источники предметов.",
      "После доставки подтвердить фактическую выгрузку в лагере."
    ]
  }
}
```

Кандидаты не передаются модели как действующие инструкции. Разработчик сначала
проверяет процедуру на отдельном мире с настоящими MCP-командами, сохраняет
отчёт с условиями и результатами и только после успешной проверки меняет
`status` на `validated`, добавляя `validationReport` с путём или ID отчёта.
Загрузчик проверяет формат этой декларации; он не запускает тесты и не доказывает
истинность указанного отчёта. Сам агент не имеет инструмента изменения каталога.

Для замены встроенного навыка используйте тот же ID и **большую** версию.
Изменения перечитываются при обращении к справке; содержимое получает новый
SHA-256 источника в диагностике. Каталог ограничен 64 записями и 256 КиБ.
Удаление локальной записи возвращает встроенную процедуру, если она существует.
Каталоги профилей изолированы. Символические ссылки на каталог или файл запрещены.

## Поиск неизвестного предмета

Встроенный `find-object` v1 отделяет поиск в памяти от физической разведки.
`self_action Explore` делает один конечный переход штатного планировщика;
ограниченный `repeat` исполняет несколько переходов без модели между ними.
После сегмента модель проверяет обновившуюся память и нужды. Выбор цели Explore
не читает скрытые предметы, не обещает новую область и не гарантирует находку.
`build-bed` v15 обращается к этой процедуре при неизвестном инструменте.

Детерминированный тест двух переходов проверяет фактическое движение, две
разные квитанции, сохранение исходной цели и ноль вызовов модели.
Это проверка исполнения навыка, а не успешная модельная приёмка поиска молотка.
[Схема реального перехода](AgentStudioChecks/2026-09-11-native-explore.svg):
13 237 узлов, 8 951 допустимая цель, 651 блокировка; радиус гекса1.5wu,
шаг субсетки0.375wu. Геометрия и выбор штатного Explore не менялись.
