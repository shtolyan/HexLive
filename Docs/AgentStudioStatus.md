# Agent Studio: состояние проверки, 11 сентября 2026

Работа по #405–410 реализована и проверяется по [утверждённому плану](AgentStudioExecutionPlan.md).
Общая приёмка длинных планов **ещё не пройдена**. #405, #406, #407, #408, #410
готовы к проверке игроком; #409 остаётся в работе. Ни один баг не помечен fixed.

## Что изменилось

- Сохраняемая цель и очередь MCP-команд исполняются отдельно от модели. Есть
  условия, ограниченные повторы и восстановление сил с продолжением исходной цели.
- Потерянный ответ сверяется с серверной квитанцией; команда с неизвестным
  исходом не отправляется повторно. Диалог и озвучка не задерживают принятую очередь.
- Агент читает текущие слоты и стаки, нужды, рецепты и ведомости стройки.
  Навыки сбора/доставки, подарка, строительства и восстановления версионируются.
- Исправлены повтор старых голосовых реплик и чрезмерные отрицательные изменения
  отношений. Сервер сохраняет подтверждённый inbox для краткого переподключения.
- Ограниченные JSONL-журналы связывают цель, очередь, шаг, команду, результат,
  задержку и доступные сведения о расходе токенов. Секреты и скрытые рассуждения
  модели не записываются. [Как разбирать журнал](AgentStudioVerification.md#технический-журнал).

## Сборка для проверки

**Studio 0.1.13** упакована из `0a562b33c10586297b73e52db33ea87d608cc191` и
проверена сертификатной подписью. Приложение находится рядом с игровыми сборками:
`~/hex-girls/Agent Studio.app`; версия сохранена в `AgentStudioReleases/v0.1.13`.
Это предварительная сборка с установленным .NET 9, не подтверждение полной приёмки.
Последующие изменения отдыха и условий очереди ещё требуют обновления пакета.

Для всей новой функции нужен совместимый сервер. Production **не обновлялся**.
Модельные сценарии используют отдельный WorldHost с настоящей симуляцией и MCP;
во время inference игровое время остановлено. Угроза, разговор и отмена дополнительно
проверены в непрерывном RunLoop, но это не готовый живой сценарий встречи с волком.
