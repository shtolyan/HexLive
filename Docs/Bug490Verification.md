# #490 — цвета и полосы в HTML-карточках предметов

При переносе карточек в HTML `StatRows` передавал только подпись и значение.
Цвет, уже вычисленный исходной карточкой UI Toolkit, и заполнение полосы
терялись. В `inventory` и `loot` оставались обычные текстовые строки.

Строки теперь содержат `[подпись, значение, цвет, заполнение|null]`. Первые
два поля сохранены для старых моделей/страниц. Цвет берётся из авторского
inline-стиля значения: карточки строятся вне панели, поэтому `resolvedStyle`
не используется. Полосы воды и прочности передают нормализованное значение;
ноль означает пустую полосу, `null` — отсутствие полосы.

Оба HTML-окна используют общий `ItemStats`. Сравнение оружия, предпочтения
и пороги состояния одежды рассчитываются прежним кодом C#, без копирования
правил в JavaScript. Вода получила янтарный цвет по просьбе игрока. Числовой
объём остаётся рядом с полосой; выбор конкретной ёмкости по source index
сохранён. Расчёт характеристик и симуляция не менялись.
