# #491 — огонь домашнего очага смещён и направлен вбок

Причина в авторском `fire_point`, а не в координатах мирового объекта.
Stage workspace содержал маркер в Blender `(-16, 0, 0)`; native FBX сохранял
это смещение. Через настоящий `HutFurnitureFactory.BuildHearth` Unity измерила
wrapper-local `(16, 0, 0)` при любом из шести поворотов. Кроме того, ось `+Y`
маркера после импорта была горизонтальной: `CampfireEffect` выбрасывал пламя
вбок. Это не ошибка смещения самого очага или его simulation junction.

Исправлен только маркер в существующем stage workspace: положение Blender
`(0, 0, 0.055)`, локальная `+Y` направлена по Blender `+Z`. Все остальные
object matrices остались прежними. Через канонический exporter перевыпущен
только `furniture.hearth.fbx` и соответствующая construction receipt. Меши,
стадии, bill из 21 детали, footprint и игровой код эффектов не менялись.

Manifest `requiredMarkerPoses` задаёт положение и up axis в авторском и
импортированном базисах. Экспорт Blender и `ConstructionStageBuildGate`
проверяют этот контракт; будущая регенерация не сможет молча вернуть
смещение или горизонтальное пламя. Прежний генератор также исправлен, но
не запускался поверх artist-edited workspace.

## Проверки

- Read-only аудит исходника и старого FBX подтвердил смещение.
- Первоначальный запуск нового теста остановился на несовместимом с Unity
  NUnit `Assert.Multiple`; тест исправлен. Следующий запуск на старом FBX
  воспроизвёл баг: ожидался X=0, получен X=16. Измерения всех шести поворотов
  сохранены отдельно, этот прогон не заявляется успешным.
- Unity 6000.4.6f1, CLI PlayMode, финал: 2/2 прошли. Production factory
  на native FBX во всех шести yaws даёт маркер `(0, 0.055, 0)`, начало пламени
  `(0, 0.0928, 0)` и направление вверх. Второй тест вызывает настоящий
  `ConstructionStageBuildGate.ValidateAll`: PASS для всех 14 моделей.
- Частицы локально просимулированы, получен и просмотрен снимок
  `hearth-after.png`. Это изолированная проверка с диагностическим светом,
  не снимок опубликованного мира.
- Независимый FBX roundtrip: 668 вершин, максимальная ошибка
  `5.372690026206328e-08 wu`, маркер совпадает с исходником.
- Отрицательные проверки Blender: смещение `(-16,0,0)` и identity rotation
  отклонены; правильная поза принята. Эти мутации не сохранялись.
- `construction_content.py verify-source`: 14 моделей, 299 деталей, PASS.
  `Tools.tests.test_construction_content`: 2/2 прошли.
- Native Release: 8/8 профильных тестов очага/строительства/структуры спеки.
  Строгая `webgl_compile_check.py`: 0 ошибок и 0 запрещённых API, exit 0.

Логи: `Build/Diagnostics/20261019-bug491/`. Схема
`Docs/Architecture/hearth-fire-anchor.svg` строится
`python Tools/generate_hearth_fire_diagram.py` из констант HexRadius /
HexPointLayout, manifest и измеренного старого X=16. Радиус гекса 1.5 wu,
шаг между центрами 2.5981 wu, смещение 16 wu = 6.16 таких шагов.

## Публикация и пределы

Player, AssetBundles и серверы не собирались/не публиковались. Реестр
и мир не менялись. Для появления исправленной модели в игре нужен
перевыпуск и публикация atomic owner `object/furniture.hearth` отдельным
разрешённым релизом. Правка игрового сервера и новый Player для этого
изменения не требуются. Проверка опубликованного bundle и мира после
сохранения/перезахода остаётся за релизным QA.
