# #492 — повторяющиеся категории HTML-крафта

`CharacterPanel.CraftModel` проверял категорию строкой через
`JArray.Contains`. Сравнение JSON token instances не обеспечивало уникальность
строковых значений, поэтому один и тот же ID дописывался для каждого рецепта.
HTML выводил полученный список без изменения: десятки кнопок одной категории.

Уникальность теперь проверяет `HashSet<string>(StringComparer.Ordinal)`.
`JArray` сохраняет порядок первого появления категорий. Все рецепты и их
детали строятся независимо от дедупликации; классификация, локализация,
выбранный фильтр и команды крафта не менялись. JavaScript и симуляция не
изменялись.

  ID для инструментов, ресурсов, еды, протезов и fallback. Это проверка модели

  живого мира здесь не выполнялись.
- Из реального C# model экспортировано 92 рецепта и 6 уникальных категорий.

  Вызовы перехватываются локальным стендом, не отправляются в игру.

  Первая попытка browser harness не передала обязательное поле capacity и
