## Совместимость состояния

Blob 88 добавляет один byte `CampfireFuelRole` в хвост каждой ItemInstance-записи
(None/Wood/Discard). Старый древесный маркер ResourceAmount=-151 при чтении v66–87
мигрирует в Wood/0. Новые записи не используют количество воды или возраст листьев как метки.
Blob 89 независимо дописывает Variant в хвост WorldObject-записи после монтажных материалов.
Чтение 87/88/89 и повторная запись загруженного мира в 89 проверены вместе с водой 4.2,
WaterKind/LastAddedWaterKind, возрастом листа 123 и ролью топлива. Доступность питья округляет
целые глотки, физические переносы и остатки не округляют. Эти хвосты сейва не меняют snapshot wire.

Обязательная зависимость #627: terminal-reset из #623 и его финальный канонический lifecycle API (`af305139d6c5de6877b0ead0169a0f1b76e83c40`).
Без него отдельный cherry-pick #627 оставлял Plant→PickUp в Active; с зависимостью 60/60
совместных focused-проверок зелёные. Не выбирать для релиза один #627 без связанных исправлений.

Новый сервер пишет save v89; старый сервер v87 такие записи не прочитает.
Перед будущим обновлением нужен отдельный rollback-снимок мира до первого сохранения v89.
