# Flashback #431 — повторная проверка причёсок, 08.11.2026

В опубликованном WebGL `player-562a3b07d` через обычный экран создания
персонажа просмотрены все 16 причёсок на Marta и Kshishtof. Персонаж в мир
не создавался. Особенно заметны просветы Classic bob / Bob3, Breeze / Eilis,
Silhouette / Jennifer; Classic bob проверен также с затылка. Это проверка
старой опубликованной версии, а не подтверждение новой правки в браузере.

Причина: восстановленный scalp пересекался с головой; общая посадка женского
исходника на мужскую голову усиливала дефект. Изменены только подложки
scalp/base/cap, пряди и исходные карты/пороги прозрачности сохранены.
Оба LOD имеют отдельные посадки для каждого тела. Мужские FBX перечислены
в `bodyFits.Kshishtof` source-manifest и снабжены hash-pinned bindings.

`Tools/Art/fit_hair_scalps.py` подразделяет подложку и исправляет пересечения
после штатного скиннинга по именам костей. Знак расстояния определяется
принадлежностью объёму через несколько лучей: нормаль одной ближайшей грани
неустойчива на рёбрах гранёной головы. Проверяются вершины, центры и середины
рёбер треугольников. Источник не перезаписывается инструментом: результат
сначала поступает в staging и устанавливается после проверки хешей.

Проверено `Tools/Art/verify_hair_scalps.py` повторным импортом всех 64 FBX:

- 64/64, ошибок нет; минимальный зазор 0.50007 мм при целевом 1.5 мм.
- Максимальное расхождение весов с sidecar: 2.98 × 10⁻⁸.
- Проверены порядок материалов, SourceUV, хеши FBX и привязки каждого
  импортированного узла. Максимальное смещение исходной подложки: 19.98 мм.
- Создана [схема реальных срезов](HairScalpFitDiagram.svg), сетка 20 мм.
- Сумма треугольников 16 стилей в обоих LOD одного тела: 125636 → 211796.
  Добавляется около 2700 треугольников на выбранный LOD одной причёски;
  число материалов не увеличено. FPS/draw calls нового контента не измерены.

Runtime проверен headless-компиляцией Windows и WebGL: ошибок нет,
запрещённых WebGL API нет. Editor-скрипты компилируются отдельно по
установленным Unity DLL: 0 ошибок; 4 предупреждения о версиях зависимостей
стенда. Unity Editor не запускался.

Перед сборкой нового контента в согласованном Editor необходимо выполнить
`PeopleAssetPreparation.ImportHairAndPrepare`: он импортирует все 64 модели,
сверяет порядок костей и bind poses, затем сохраняет мужские LOD в
`WearConfig.hairLodMeshes` существующих 16 префабов. Runtime выбирает меши
до сшивания со скелетом; трансформами посадка не исправляется.

Новая подготовка префабов в Unity, сборка/публикация AssetBundles и повторная
визуальная проверка уже исправленного опубликованного WebGL ещё не выполнены.
Состояние production не менялось. Исходные хеши и результаты измерений:
