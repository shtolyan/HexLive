# Редактор персонажа — проверка доработки §162

Статус: код внесён; обязательная приёмка в Unity **не завершена**.

## Реализация

- `LobbyCharacterEditor`: постоянные имя/лагерь/предпросмотр, два раздела,
  восемь вкладок, плитки, поиск, отдельная панель расцветок и снятия вещи.
- `LobbyWardrobeRules`: группировка по prototypeId, атомарная замена расцветки,
  проверка серверных slots/layers с прежним fallback на covers, сохранение
  совместимого комплекта при смене тела.
- `LobbyCharacterPreview`: тело загружается только при смене Body; остальные
  части применяются к текущему NpcActorView. Камера управляется манипулятором
  области изображения. Фон игрового портрета, два локальных источника света.
- `NpcActorView`: режим примерочной без покраски ран и idle-fidgets,
  инкрементальная кожа/глаза, поколение запроса волос. Уничтоженные или
  устаревшие получатели не применяют запоздавшие результаты загрузки.
- `LobbyAppearanceThumbnails`: последовательная съёмка настоящих ассетов,
  запросы только от видимых плиток, кэш небольших текстур; глаза и голова
  кадрируются по лицевому якорю игрового портрета.
- Внешние форматы и серверный API этой доработкой не менялись.
  Старый пустой HairColour сохраняет вычисление цвета по исходному npcId,
  даже при отдельном идентификаторе экземпляра примерочной.

Unity MCP трижды вернул `instance_count: 0`. Новый Editor не запускался;
аренда `lobby-wardrobe` освобождена после проверок доступности.

3. Все доступные тела, кожа, глаза, волосы, их миниатюры и расцветки;
   головные уборы и движение волос, совместимость одежды каждого пола.

   `LobbyCharacterPreviewTests.AppearanceChangesKeepAnimatorAndBodyChangeReplacesIt`,
   требующий доступного игрового каталога выбранного сервера; **ещё не запускался**.
5. Полный рост в начальном кадре, мягкий свет на коже и белой одежде,
   ПКМ/колесо/СКМ только над предпросмотром и восстановление камеры.
6. Поиск/прокрутка/выбор вкладок, отказ конфликта без потери комплекта,
   локальный черновик после закрытия и повторного открытия.
7. Недоступный ассет, быстрый выход во время загрузки, отсутствие возврата
   устаревшей причёски и ошибок уничтоженных объектов в Console.

и голосового интерфейса не относятся к этой доработке.
