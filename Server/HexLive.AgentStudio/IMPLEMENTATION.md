## Реализовано в исходниках

- Общее `HexLive.AgentCore` для CLI и desktop (net8/net9).
- Типы профилей, отдельные модельные/голосовые интерфейсы.
- Постоянное хранение профилей с optimistic concurrency; независимые настройки
  провайдера, модели, reasoning и голоса в окне выбранного профиля. Создание
  Ники не копирует биографию Маши; существующая память сохраняет свою личность.
- Окно интеграций записывает ключи через системное хранилище; списки моделей
  и ElevenLabs-голосов загружаются без генерации. Codex model/list через
  официальный app-server проверен реальным бесплатным запросом каталога.
- Фабрика реальной MCP-сессии использует настройки одного профиля, проверяет
  точный мир/NPC и создаёт независимые модельный и голосовой адаптеры.
- HTTP-адаптеры OpenAI Responses, Grok, Claude Messages, DeepSeek; отдельный
  режим thinking DeepSeek. Извлекается только финальный ответ, не reasoning.
- Адаптеры существующего Codex runner и ElevenLabs; режим без озвучки.
- Ядро ручного запуска/остановки с эксклюзивной блокировкой workspace.
- Менеджер нескольких агентов: независимые настройки одного запуска,
  остановка выбранного профиля/всех, запрет изменения активного запуска.
  Проверен fake-сценарий одновременной Маши/Grok и Ники/DeepSeek с разными
  голосами; это ещё не игровой production acceptance.
- AgentHost больше не запускает/останавливает модель по player presence:
  учитывается пауза мира. Добавлено закрепление NPC/world между reconnect.
- Серверный `world_status` передаёт стабильный `worldId`.
- Хранилище подтверждений и хешей MCP credentials, привязка сессий к миру и
  credential, scoped-вызовы MCP и фильтрация NPC. Подключено в Program и /watch;
  окно серверов получает одноразовый код, меню Escape подтверждает доступ.
  Endpoint проверен локальным HTTP-тестом, Unity-панель пока не компилировалась.
- Главное окно: подключение сервера без LLM, выбор разрешённого NPC, запуск,
  остановка выбранного/всех, закрытие с остановкой или отменой. Отображаются
  пауза/reconnect и последнее краткое намерение; tray пока отсутствует.
- Независимый механизм отношений: плюс/минус/ноль, отрицательная симпатия,
  ограниченные шаги, дедупликация сообщений, обязательный блок промпта.
- AES-GCM codec и парольное шифрование; нативные адаптеры Keychain/Credential
  Manager. Реальное системное хранилище ещё не прошло OS acceptance.
- Markdown-редактор с проверкой версии, резервной копией, запретом путей к
  служебному состоянию и защитой от потери несохранённых изменений в UI.
- SOUL/USER не перезаписываются генератором. Известный шаблон безусловной
  привязанности мигрирует с backup. Импортированное прозвище остаётся в промпте.
- Добавлены общий document write lock, сохранение редактированных generated
  Markdown-заметок и просмотр/загрузка истории. Эти последние изменения пока
  не проверены сборкой: обнаружен открытый Unity другого проекта.
- Avalonia: каркас окна, светлая/тёмная тема, RU/EN, редактор Markdown.
- Восстановлен визуальный эталон в Docs/AgentStudioDesign. В исходниках обновлены
  общие графитовые/светлые поверхности, двухколоночные настройки главного окна,
  навигация интеграций/памяти и компактный диалог выхода с безопасной отменой.
  Визуальное соответствие ещё не подтверждено новой сборкой.
- Память выбранного профиля читается непосредственно во вкладках: MEMORY.md,
  SOUL.md, список Markdown дневников/миров/импортов и открытие выбранного файла
  в редакторе. Activity показывает отдельно текущий статус и последние 32
  сохранённых намерения/записи дневника. Чтение не создаёт runtime или память.
  Кнопки Connect/Start/Stop получили векторные значки соединения/Play/Stop.
  Эти изменения ожидают сборки и визуальной проверки после подтверждения,
  что Unity Editor закрыт; открытый прежний preview пока не обновлён.

## Обязательные оставшиеся работы — до пользовательского релиза

- Сквозная проверка игрового подтверждения и UI-подключения, sender identity.
- Tray/background, конкретные причины ошибок и повторная проверка UI lifecycle.
- Проверить OS credentials на Windows, закончить встроенный Codex login,
  поддержку проверенных reasoning capabilities у каждого провайдера.
- Приёмка живого диалога на согласованных сервере/клиенте v15: per-speaker
  хранилище, relationshipAssessment и transactional outbox уже связаны (§163.3a).
  Мат/тон собственной реплики не начисляет доверие или симпатию; шаги применяет VoiceRelationship.
- Связать шифрование с реальным служебным состоянием и миграцией; реализовать
  полный импорт/экспорт архива с фильтрацией credentials и проверкой конфликтов.
- Проверить последние изменения координации writers/истории. Сторонний редактор,
  не использующий наш lock, всё ещё может попасть в окно между CAS и rename.
- Продолжить устранение legacy Masha-specific названий внутренних моделей:
  создание новой личности и выбор стиля независимы; старые имена классов сохранены для совместимости архивов.
- Визуальная приёмка имени голоса/отрицательной симпатии в Unity; код и локализация обновлены.
- Все fake-контракты, полный regression suite, OS-scale/visual acceptance,
  Windows native checks и ограниченные реальные проверки интеграций.
- Подписанная упаковка приложения, обновление CLI и согласованный rollout.

## Локальная сборка

Характер Маши, отношения по собеседникам и игровое время внедрены в общее ядро.
Подробная проверка и точный статус приёмки: [MASHA_DIALOGUE_REVIEW.md](MASHA_DIALOGUE_REVIEW.md).
Настройка `masha-sharp-v1` мигрирует только авторский workspace Маши;
модель и реальные численные отношения автоматически не поднимаются.

При закрытом Unity Editor:

```sh
dotnet build Server/HexLive.AgentStudio/HexLive.AgentStudio.csproj -c Release
dotnet test Tests/HexLive.AgentCore.Tests/HexLive.AgentCore.Tests.csproj
dotnet test Tests/HexLive.AgentHost.Tests/HexLive.AgentHost.Tests.csproj
```

Сборка desktop сейчас — framework-dependent preview, не готовый installer.
Нельзя обновлять только установленный AgentHost: новая проверка world ID требует
согласованной серверной версии. Пользователь разрешил тестовый production rollout
после сохранения прежнего мира; точка отката и границы разрешения записаны в
`Docs/AgentStudioRollout.md`. Это не отменяет проверок перед развёртыванием.
