## §161 Голосовой режим администратора

### §161.1 Контур и доступ

Админский голос — отдельный разговор клиента, без тела NPC и attachment.
FMOD/Deepgram (§160) дают финальный текст; `/watch` переносит его и контекст
выбора. Отдельный AdminAgentHost на сервере запускает Codex App Server через
stdio, ChatGPT device-code auth, модель `gpt-6-astra`, effort `medium`.
Модель вызывается только по запросу. Нет фонового LLM heartbeat, shell или
произвольного кода. Недоступная подписка/модель не включает платный API.

Веб-администратор выдаёт пятиминутный одноразовый код для canonical clientId.
Обмен возвращает индивидуальный секрет, сервер хранит только SHA-256.
Повторная привязка заменяет секрет, отзыв немедленно запрещает команды.
Общий player/MCP bearer и знание clientId не дают админских прав.
Секрет клиента хранится средствами ОС. Весь внешний транспорт — TLS.

### §161.2 Шина

`AdminCommand`/`AdminCommandResult` и `WorldHost.SubmitAdminCommand` — единственный
путь изменения мира для админки. Обработчики работают под блокировкой host,
включая паузу. Обычные приказы §145 не получают новых привилегий.
Сервер проверяет права, generation, тип и аргументы каждой команды.
OperationId дедуплицируется, журнал содержит автора, нормализованную команду и
результат. Неопределённый исход после сбоя требует проверки, не повторного
автоматического исполнения. Голос и полные разговоры не пишутся в журнал.

Удаление предметов, очистка инвентаря, удаление NPC и снос требуют отдельного
подтверждения точной команды и состояния цели в пределах 60 секунд.
«Да» поступает от клиента; модель не может подтвердить за него.
Цепочки последовательны и останавливаются на первом отказе.

### §161.3 Медицинские команды

heal закрывает раны, восстанавливает существующие части тела. Полное лечение
восстанавливает кровь и снимает умирание/кому у живого NPC, но не ампутацию.
restore_limb возвращает здоровую биологическую ArmL/ArmR/LegL/LegR, снимает
Severed и локальные травмы. target=all восстанавливает все утраченные части.
Без указанной части несколько кандидатов требуют уточнения. Умершие не
воскрешаются. Старый отрубленный мировой объект не требуется и не удаляется.

fit_prosthetic создаёт и сразу устанавливает поддерживаемый совместимый протез,
без врача/кровати/материалов/ожидания; раны культи закрываются, Severed остаётся.
repair_prosthetic восстанавливает condition. best выбирается по Function,
затем MaxCondition, затем ordinal DefinitionId. Сегодня поддерживаются
деревянные и механические руки/ноги из §118. Обычная операция использует ту же
фабрику устройства, но сохраняет все медицинские требования.

При замене или регенерации старое устройство возвращается в инвентарь с прежней
относительной прочностью. Нет места — отказ без изменений. Установка на целую
конечность запрещена; повтор не создаёт копий. После изменения пересчитываются
экипировка, вместимость и переход в стоячую позу через GrantStandUpGrace.

### §161.4 Остальные команды и интерфейс

Нужды: Hunger/Thirst/Energy/Comfort/Social/Compassion/ThermalDiscomfort/Stamina/
Breath/Hygiene/Blood/Stress; all даёт здоровые значения с учётом направления шкал.
Семь базовых AttributeKind: set/add в диапазоне 0..1. Предметы — только реальные
переносимые определения каталога, 1..1000 экземпляров, с проверкой вместимости
всей выдачи. Очистка затрагивает переносимый инвентарь, не надетые вещи.
NPC: создание по поддерживаемому пресету, имя, фракция, назначение, удаление.
Постройки: создание готовой, завершение, пополнение материалов, ремонт, снос
через штатные фабрики и правила геометрии §120.

Минимальная UI Toolkit-панель: привязка, микрофон, запасной текстовый ввод,
состояние, ответ, подтверждение/отмена. Нажатие микрофона открывает общий
`PlayerVoiceCaptureOverlay` из §160 с иконкой, 18 полосками RMS, «Готово» и
«Отмена», с пометкой «Админ». Используются тот же `FmodMicrophoneCapture`,
master mute, 3 секунды тишины и Deepgram-модуль. Отмена не отправляет команду;
потеря соединения, loading/replay и disable прекращают захват. Контекст NPC
фиксируется при начале записи. Админка ждёт результат текущей команды перед
следующей записью; очередь разговора с персонажем остаётся самостоятельной.
Фиксированные строки — I2 EN/RU.
Стиль панели встроен как bootstrap UI в `Resources/HexLive/UI/AdminVoice.uss`;
он доступен до загрузки Asset API и проходит общий Player content gate.
Ответы текстовые; Deepgram оплачивается отдельно от Codex. Бессмертие,
воскрешение умерших, редактирование навыков/черт и управление save/newworld — позже.

### §161.5 Проверка

Серверные проверки прав/отзыва/подмены id; идемпотентность и неопределённый
результат; подтверждение и смена состояния/мира. Все четыре конечности,
полное восстановление, протезы/ремонт/замена/совместимость/переполненный
инвентарь и save/load. Round-trip новых wire frames. Fake Codex/STT turn,
таймаут/ошибка провайдера, отсутствие фоновых запросов и повторного выполнения.
Unity проверяет позу, рабочую руку, протезы и текстовый/голосовой интерфейс.
