## §166 Обновление клиента через Google Drive (iteration 166)

Игрок узнаёт о новой версии внутри клиента и устанавливает её без отдельного
лаунчера. Agent Studio имеет независимый цикл выпуска и этим обновлятором не изменяется.

### §166.1 Пользовательский сценарий

macOS и Windows, канал stable. Проверка при запуске и каждые 30 минут по времени,
не зависящему от паузы. Скачивание только по кнопке; размер, описание EN/RU,
прогресс, отмена и повтор. Установка и перезапуск требуют отдельного нажатия.
Версия ниже minimumVersion не входит в мир; начатая сессия не прерывается.
Недоступность проверки не создаёт запрет; ранее проверенный запрет сохраняется.

### §166.2 Выпуск и доверие

Drive: закрытая папка HexLive Releases владельца natepo4ty@gmail.com,
Client и AgentStudio отдельно. Архивы неизменяемы. stable-метаданные публикуются
последними. Envelope содержит base64 payload (UTF-8 JSON) и base64 RSA-3072+
PKCS#1 SHA-256 signature именно этих байтов. Публичный ключ встроен в Player
и helper; закрытый ключ никогда не хранится в репозитории/Drive/клиенте.
Manifest: schemaVersion=1, product=client, channel=stable, platform,
architecture, version, minimumVersion (MAJOR.MINOR.PATCH), publishedUtc,
notesEn, notesRu, driveFileId, sha256, size, unpackedSize.

Сервер каждую минуту читает метаданные через Drive API, проверяет подпись,
скачивает и проверяет архив, лишь после этого атомарно меняет свой latest.
Ошибки не уничтожают последний исправный выпуск. HTTPS API v2 использует ETag
и Range; v1 Windows сохраняется. Google credentials доступны только издателю
и синхронизатору, не публичной раздаче. Asset API не меняется.

### §166.3 Установка

Полный архив, возобновляемая загрузка, SHA-256 перед распаковкой. Helper работает
из временной копии вне заменяемого приложения, ждёт завершения процесса,
создаёт новую версию и переключает symlink/junction. Journal позволяет восстановить
прерванное переключение. Не перезаписывает старые версии, сохранения или настройки.
Подтверждение нового процесса означает готовность главного меню, а не загрузку мира.
Если новый процесс не подтвердился за 120 секунд, helper останавливает только
запущенный им процесс и возвращает прежнюю версию. Хеш неудачного выпуска
подавляет автоматические повторы; ручная попытка разрешена.

На macOS переключение существующего latest-symlink выполняется атомарной
заменой ссылки: приложение не исчезает между удалением старой ссылки и
созданием новой. Относительная ссылка предыдущей версии сохраняет исходную
цель при резервировании. Подтверждение содержит точную версию установленного
выпуска; чужое/пустое подтверждение не означает успех. При восстановлении
журнала уже подтверждённый запуск сохраняется, незавершённое переключение
откатывается, включая случай оборванной ссылки на новую версию.

Адрес канала — `https://163-245-204-96.sslip.io/api/releases/v2/client`.
Проверка готовности публикации отдельно проверяет упаковку helper для всех
архитектур, подпись и ticket macOS и доступность HTTPS канала. Локальные тесты
установочного механизма не заменяют приёмку двух подписанных Player-сборок.

### §166.4 Публикация

Только штатные build_release.py/build_release_windows.py; helper добавляется
до окончательной macOS подписи. Публичный macOS выпуск требует Developer ID,
нотарификацию и stapled ticket по Tools/MACOS_SIGNING.md. Никаких обходов
проверки подписи. Первый клиент устанавливается вручную. Публикация отдельной
командой, никогда не побочный эффект локальной сборки.
