## 2. Tick System (FOUNDATION)

Tick = atomic simulation step

**Everything in the game evolves through ticks:**

- movement
- AI
- perception
- memory
- social
- interactions

### 2.1 Tick Layers

**Fast:**

- movement
- rotation
- execution

**Medium:**

- perception
- needs
- decisions

**Slow:**

- long-term goals
- environment

### 2.2 Rule

NOTHING depends on Unity frame updates
