# Проверка памяти Agent Studio — §165

Состояние на 2026-09-10: реализация и автоматические проверки готовы.
Выпуск v0.1.9 не опубликован: штатная подпись завершилась
`errSecInternalComponent`. После разблокировки Mac ошибка повторилась также
на чистой сборке (`Build/AgentStudioMemoryRelease`) и на отдельной временной
копии исполняемого файла. Системный журнал уточнил причину:
`SecKeyCreateSignature`, `errSecAuthFailed`, `CSSMERR_CSP_OPERATION_AUTH_DENIED`.
Пользователь подтвердил тот же отказ при запуске из обычного Terminal.
Preflight теперь проверяет настоящую подпись временного файла до упаковки;
3 проверки нового preflight и 6 проверок упаковщика прошли.
Нужно восстановить разрешённый доступ к существующему ключу подписи в Keychain;
сертификат и требования проверки не изменялись. Последняя опубликованная
версия — v0.1.8. Визуальная проверка нового окна также пока не завершена:
при открытии Keychain инструмент снова сообщил о блокировке Mac.
Рабочий профиль ещё не мигрирован;
первая миграция выполняется при запуске нового агента либо открытии архива
остановленного профиля, после резервного сохранения состояния.

Локальные результаты: `Build/MemoryAcceptance/model-answers.json` и

Повторение явных тестов (из корня проекта):

```sh
dotnet test Tests/HexLive.AgentCore.Tests --filter FullyQualifiedName~HundredThousandRecordBenchmark
HEXLIVE_MEMORY_COPY=/path/to/offline-copy dotnet test Tests/HexLive.AgentCore.Tests --filter FullyQualifiedName~OfflineWorkspaceCopyMigration
HEXLIVE_CODEX_SMOKE_EXECUTABLE=/Applications/ChatGPT.app/Contents/Resources/codex HEXLIVE_MEMORY_EVAL_MODEL=gpt-6-astra HEXLIVE_MEMORY_EVAL_OUTPUT=/path/to/results dotnet test Tests/HexLive.AgentCore.Tests --filter FullyQualifiedName~MemoryModelAcceptanceTests
```

Последний тест использует настоящую модель и только синтетические записи;
не подключается к игровому серверу и не отправляет реплики игроку.
Выбирать модель явно. Перед компиляцией выполнять правила `CLAUDE.md`.

Ограничения: сервер и его кольцевой журнал не изменены. Во время выключенной
Studio события могут исчезнуть из кольца. У полученных старых событий известен
игровой тик, но может отсутствовать календарная дата. Старые дневники iPhone
были сокращены ещё исходным приложением; отсутствующие окончания разговоров
не восстанавливаются. Windows и другие реальные провайдеры в этом прогоне
не проверялись; общий контракт покрыт автоматическими тестами адаптеров.
