# wardrobe — конвейер добавления одежды

Превращает архив с ассетами DAZ в готовые Wear-префабы HexLive. Стадии
разнесены по отдельным командам намеренно: агент-надзиратель запускает их по
одной и читает JSON-отчёт, поэтому падение — это маленький названный шаг, а не
непрозрачный часовой скрипт.

```bash
python -m wardrobe check
python -m wardrobe dress --drop sweetjane --garment "<...>/Sweet Jane Skirt.duf" --garment "<...>/Sweet Jane Tank.duf"
python -m wardrobe build --drop sweetjane
python -m wardrobe show  --drop sweetjane
```

## Что делает каждая стадия

| стадия | что происходит |
|---|---|
| `check` | пути, внешние программы, живость DAZ Studio |
| `dress` | по каждой девушке: открыть сцену, снять всё надетое, надеть новое, выгрузить FBX |
| `build` | перенести текстуры в проект и составить черновик манифеста |
| `show` | показать манифест вместе с доказательствами (облако вершин по зонам тела) |

Дальше Unity сама собирает префабы: экстрактор читает
`Assets/Editor/WearDrops/<drop>.json`, поэтому **новая одежда не требует правок C#**.

## Что решает человек

Черновик манифеста — это предложение, а не приговор. Проверять нужно:

- `simId`, `name`, `folder` — генератор даёт заглушки вроде `clothing.skirt`;
- `layer` — всегда предлагается `Wear`;
- `slots` — выводятся из геометрии, рядом лежит `_measured.zones` с долями
  вершин по зонам тела, чтобы догадку можно было проверить, а не поверить в неё.

Повторный `build` **не трогает** уже проверенные поля: он обновляет только
замеры и добавляет вещи, которых раньше не было.

## Грабли, за которые заплачено

- **Сервер DAZ принимает поле `args`, но никогда его не связывает** — скрипт
  падает с `ReferenceError: Can't find variable: args`. Клиент вшивает
  параметры в текст скрипта.
- **Экспорт FBX только через `DzFbxExporter` напрямую**, с `RunSilent`: иначе
  модальный диалог вешает сервер. MCP-инструмент `daz_export_fbx` сломан —
  зовёт несуществующий `DzExportMgr.doExport`.
- **`IncludeMorphs=false`** превращает 64 МБ в 9 МБ и ничего не теряет.
- **Габаритный ящик — плохое описание вещи.** У расклешённой юбки он достаёт до
  плеч, у пары рукавов включает пустую грудь между ними. Слоты считаются по
  облаку вершин.
- Плагин DAZ подхватывается только при СТАРТЕ студии, и сервер надо включить
  руками: Window → Panes → Daz Script Server → Start Server.
